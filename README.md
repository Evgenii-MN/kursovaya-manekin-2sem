# АС «База автомобильного салона»

Курсовая работа. Манекин Е.Н., группа ЗПИуд-123.

## Запуск
Windows с .NET Framework 4.8. Выполнить build.cmd, затем
src\AutoSalon\bin\AutoSalon.exe. Для Visual Studio — AutoSalon.sln.

Меню: стрелки ↑ ↓, Enter открыть пункт, Esc назад.
Начните с добавления автомобиля и клиента; затем оформите продажу.
VIN — 17 знаков без I, O и Q. Цена вводится без пробелов, с запятой.
Резерв — складской статус; перед продажей его нужно снять.

Данные создаются при первом запуске в bin/data/salon.json.
Резервная копия хранит предыдущее исправное состояние. Восстановление
может потерять последнюю операцию. При восстановлении из копии
выводится сообщение. Для записи используется файловая блокировка,
данные перечитываются после её получения и записываются атомарной заменой.

## Три функции
- Каталог: добавление, поиск, изменение цены, резерв и снятие резерва.
- Клиенты: карточка, список, история покупок.
- Продажи: оформление, журнал, итог и учебная карточка сделки.

Функциональные ветки: feature/catalog, feature/clients, feature/sales.
Интеграция: final → master → main.

## Проверки
src\AutoSalon\bin\AutoSalon.exe --test work\new-test

src\AutoSalon\bin\AutoSalon.exe --demo work\new-demo

Папки проверки должны быть новыми и пустыми. Набор содержит 36 проверок;
два независимых экземпляра хранилища проверяются параллельно.
Протокол — evidence/test-output.txt, результаты — evidence/results.json.

## Границы программы
Консольный демонстратор трёх функций учебного проекта.
Целевая архитектура React / Django REST Framework / PostgreSQL
в демонстраторе не реализована. Нет защищённой авторизации,
email/SMS, генерации юридических договоров, фискальных документов,
промышленной эксплуатации и распределённой оффлайн-синхронизации.
Карточка сделки — учебный вывод.
Блокировка проверена локально; сетевые файловые системы не проверены.
Телефон и email проверяются по формату, фактическая доставка не проверяется.

## Состояние проверки

Протокол относится к предыдущей сборке. В окончательном исходном коде добавлены проверки точности цены; повторный локальный прогон не выполнялся. См. evidence/validation-scope.txt. Готовые EXE/DLL не передаются. Обнаруженный антивирусом AutoSalon.exe не включён и не должен восстанавливаться из карантина ради запуска проекта.
